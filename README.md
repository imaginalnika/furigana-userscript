# ふりがな・ひらがな (Safari Userscript)

Install in the free [Userscripts](https://apps.apple.com/app/id1463298887) iOS app:

1. Enable the Userscripts Safari extension (Always Allow / needed sites).
2. Open this raw URL in Safari (path must end in `.user.js`):

   `https://raw.githubusercontent.com/imaginalnika/furigana-userscript/main/furigana.user.js`

3. Open the Userscripts extension popup and accept the install prompt.

Or save `furigana.user.js` into your Userscripts folder via the Files app.

No runtime network requests; readings stay on-device. Dictionary derived from IPADIC (see notices in the script / LICENSES.txt).
